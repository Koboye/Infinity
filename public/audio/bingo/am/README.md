# Amharic Bingo caller clips (optional)

Drop recorded clips here and the caller plays them automatically: first the letter, then the number.

- Letters: `B.mp3`, `I.mp3`, `N.mp3`, `G.mp3`, `O.mp3` (say ቢ, አይ, ኤን, ጂ, ኦ)
- Numbers: `1.mp3` … `75.mp3` (say አንድ … ሰባ አምስት)

Without these files the caller uses an Amharic text-to-speech voice if the phone has one, otherwise it reads the ball in English.
