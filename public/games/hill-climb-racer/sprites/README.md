Drop these PNGs here (transparent background, side view, vehicle FACING RIGHT,
**no wheels** – the game draws and spins the wheels itself, rider INCLUDED):

    buggy.png  jeep.png  truck.png  monster.png  sports-car.png

original artwork only (no third-party logos/brands/characters).
