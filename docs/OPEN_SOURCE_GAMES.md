# Open-Source Games Worth Playing

A curated list of free, open-source games, grouped by type.

## Puzzle and brain games
- **Simon Tatham's Puzzle Collection**: about 40 logic puzzles (Android and PC)
- **Open Sudoku**: simple, ad-free Sudoku (Android)

## Addictive / "one more turn"
- **Shattered Pixel Dungeon**: polished roguelike (Android, PC)
- **Unciv**: open-source Civilization V remake (Android, PC)
- **Mindustry**: factory building and tower defense (Android, PC)
- **OpenTTD**: transport management (PC)
- **Cataclysm: Dark Days Ahead**: deep survival game (PC)

## Best 3D games
- **SuperTuxKart**: colorful kart racer with online multiplayer
- **0 A.D.**: historical real-time strategy, Age of Empires style
- **Xonotic**: fast arena shooter, Quake style
- **Veloren**: multiplayer voxel RPG
- **Luanti (formerly Minetest)**: moddable sandbox
- **Warzone 2100**: classic real-time strategy

## Car stunts and driving
- **Stunt Rally**: rally and stunt racing with ramps, loops and jumps
- **Rigs of Rods**: soft-body physics vehicle simulator
- **Ultimate Stunts**: remake of the DOS game Stunts (inactive since 2017)
- **Trigger Rally**: off-road rally
- **Speed Dreams**: motorsport simulator

## Football
- **YSoccer**: retro top-down football in the style of Sensible Soccer

## Other
- **Battle for Wesnoth**: turn-based fantasy strategy
- **Hedgewars**: turn-based Worms-style game
- **Endless Sky**: space trading and combat
- **Frozen Bubble**: bubble shooter
- **Lichess**: open-source chess platform

Most Android titles are on F-Droid; source code for all is on GitHub or SourceForge.
